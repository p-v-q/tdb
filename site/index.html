The database client that lives in your terminal.

Built for the keyboard, honest about the mouse.

Every pane is reachable from the home row; the mouse works too.

Browse and write

Capability-aware object trees, generated SQL for tables and views, and context-aware completion against the live catalog.

Inspect results

Sort, filter, resize and copy cells or rows. Export CSV, TSV, JSON or Markdown; scripts keep multiple result sets.

Edit safely

Read-only mode, confirmations for risky statements, pending parameterized updates and manual transactions with commit or rollback.

Work your way

Saved connections, server-fed pickers, passwordEnv, an encrypted vault, named tabs, themes and two interface languages.

  • Nerd Font icons by default, portable symbols when you turn them off
  • PBKDF2-HMAC-SHA256 + AES-256-GCM sealed connection list
  • CJK and emoji width aware — grid columns line up
  • Cancelable statements and a 1,000-row cap with a truncation notice
  • Offline demo catalog for trying the UI without a database
  • Dark and light themes, English and 简体中文

With Go

Use the version in go.mod or newer.

go install github.com/p-v-q/tdb/cmd/tdb@latest

Container

Published for linux/amd64 and linux/arm64.

docker run --rm -it -v "$HOME/.config/tdb:/home/tdb/.config/tdb" ghcr.io/p-v-q/tdb:latest

Quick start

tdb                                      # offline demo catalog
tdb -d sqlite -dsn shop.db               # open or create a SQLite database
tdb -d postgres -dsn 'postgres://user:pass@localhost:5432/shop?sslmode=disable'
tdb -d mysql    -dsn 'user:pass@tcp(localhost:3306)/shop'
tdb -lang zh-Hans                        # force Simplified Chinese

Press F5 to run, F1 for key bindings and F2 for settings.

Four drivers, one interface.

Identifiers are quoted per dialect and statements are cancelable across all SQL drivers.

PostgreSQL

Schemas, tables, views, materialized views, functions, procedures, triggers, indexes and sequences. SSL modes, search_path default schema.

pgx v5

MySQL

Tables, views, routines, triggers, functional and multi-valued indexes, generated columns, JSON and TLS modes.

MySQL 8+

MariaDB

The MySQL driver and dialect, plus system-versioned tables and sequences.

MariaDB 11+

SQLite

Pure-Go modernc.org/sqlite: tables, views, triggers, indexes, generated columns and attached databases. No CGO.
